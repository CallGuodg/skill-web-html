# 网页转单文件 HTML

把一个网页转换并保存为**单个 HTML 文件**，断网后仍能完整阅读：图片以原图内联，
表格、样式和插图一并内联，产物里不残留需要联网才能加载的资源引用。

> **状态：骨架。** 元数据与发布链路已就绪，抓取、正文提取、资源内联的实现尚未落地。
> 实现补齐前请只做本地预检，不要打 tag 正式发布。

## 何时使用

- 用户要求把某个网页文章保存到本地、做离线归档。
- 需要长期留档，且不希望内容随原站改版或下线而丢失。
- 需要把图文混排的长文原样保存，而不是只留纯文本。

## 目标产物

- 单个 `.html` 文件，双击即可用浏览器打开。
- 图片以 base64 内联，不依赖外部图床。
- 样式内联，链接与表格保留原有结构。
- 不执行页面里的脚本，不保留追踪与广告资源。

## 不做什么

- 不抓取需要登录、付费或明确禁止存档的内容。
- 不执行下载到的网页脚本，不把远程脚本内联进产物。
- 不修改源网页，不向第三方回传抓取内容。

## 权限声明

- 网络访问：仅访问用户显式给出的目标 URL 及其页面内资源地址。
- 文件读写：仅写入用户指定的输出路径。
- 环境变量：不读取任何凭证，不依赖外部 API Key。
