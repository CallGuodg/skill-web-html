# 实现笔记（占位）

本文件随 Skill 一起打包，用来记录实现取舍。当前项目处于骨架阶段，以下是规划中的要点，
落地实现时请同步更新，避免文档与代码不一致（`preflight.py` 会检查文档引用的文件是否存在）。

## 抓取

- 只请求用户显式给出的 URL，以及该页面内引用的图片、样式资源。
- 设置合理超时与重试上限，失败时明确报错，不产出半成品文件。
- 尊重 robots 与版权，不处理需要登录或付费的内容。

## 正文提取

- 优先保留文章主体，剔除导航、广告、评论区与追踪脚本。
- 保留标题、发布时间、来源链接等元信息，便于离线追溯。

## 资源内联

- 图片转 base64 data URI，注意体积膨胀，单文件设置上限。
- 样式内联，移除 `@import` 与外部字体依赖。
- 不内联任何可执行脚本，避免离线打开时触发未知行为。

## 输出

- 默认写单个 `.html` 文件到用户指定路径。
- 输出 UTF-8，显式声明 charset，避免中文乱码。
- 提供简要校验：产物能被浏览器打开、无残留外链请求。
